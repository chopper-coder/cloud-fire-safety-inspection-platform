# 政府採購 AI 測驗平台 V4.2.0

**Legal Verification & Exam Analytics Edition**

以 V4.1.0 為基礎升級的純前端測驗平台，可直接部署到 GitHub Pages。資料只儲存在使用者自己的瀏覽器。

## 本版重點

- 題數答對率與 2／5 分加權得分率分開呈現。
- 以不重複題目計算題庫覆蓋率及學習等級。
- 新增每題作答次數、最後出現時間、正確次數及平均作答秒數。
- 智慧練習可避開最近 3／7／14／30 日做過的題目。
- 新增學習分析頁、測驗趨勢、題型分析、科目加權表現及常錯法條。
- 新增法條專項與易混淆法條比較練習。
- 新增法源驗證狀態，清楚區分官方摘要核對、題目明示、推定與科目範圍。
- 移除 3 筆完全重複題目，保留舊 ID 對照以移轉既有資料；有效題庫為 3,664 題。
- 新增 PWA 安裝、離線快取及新版更新通知。
- 新增診斷報告匯出。

## 法源驗證範圍

`data/verified_legal_data.js` 收錄核心法規的官方代碼、修正日期、已核對核心條文清單及易混淆法條組合。

「核心摘要已核對」表示法規名稱、官方連結、修正日期與摘要已對照官方法規資料；**不表示全部題目答案與法源關係均經逐題人工認證**。題目未能確定具體法源時仍會標示為推定或科目範圍。

## GitHub Pages 更新

把壓縮檔解壓後，將所有檔案及資料夾上傳到 repository 根目錄並覆蓋同名檔案。請確認新增檔案一併上傳：

- `manifest.webmanifest`
- `service-worker.js`
- `data/verified_legal_data.js`
- `icons/`

更新後若仍看到舊版，網站上方會出現「立即更新」；也可在平台設定中按「檢查更新」。

## 部署後驗收

GitHub Pages更新完成後，建議依序測試：開始20題練習、交卷、學習分析、加入主畫面、關閉網路後重新開啟，以及下一次更新時的版本通知。PWA實際安裝驗收需在正式HTTPS網址進行。
