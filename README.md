# 政府採購 AI 學習平台 V5.1.5 Theme Initialization Fix Edition

政府採購 AI 學習平台是一套可直接部署於 GitHub Pages 的純前端學習系統。題庫、學習紀錄、AI 採購老師、案例研習與法條比較均在使用者瀏覽器本機運作，不需後端伺服器或 API 金鑰。

## 主要功能

- 3,664 題政府採購學習題庫
- AI 採購老師、案例研習與法條比較中心
- 正式三節模擬、快速測驗、智慧弱點練習及錯題間隔複習
- 答對率、加權得分率、題庫覆蓋率與學習趨勢
- PWA 安裝、離線快取與本機資料備份
- 電腦、平板及手機響應式介面

## V5.1.5 更新重點

本版修正無痕模式與第一次開啟網站時的配色初始化問題：

- 在 `index.html` 內加入最小化關鍵首屏樣式。
- 即使 `style.css` 尚未載入，桌機左側欄仍會直接顯示深藍漸層，不再短暫變成白色。
- 預載 `style.css`，降低首次載入的無樣式閃爍。
- 側邊欄導覽按鈕明確設定透明背景與透明邊框，避免套用瀏覽器預設白色按鈕。
- 統一桌機側邊欄、手機頂部列、底部導覽及更多功能抽屜的藍綠配色。
- 保留 V5.1.4 的測試可靠性、正式三節模擬及備份資料完整性修正。

## GitHub Pages 部署

1. 解壓縮完整版。
2. 將解壓後的全部檔案與資料夾上傳到儲存庫根目錄。
3. 確認 `index.html` 位於根目錄。
4. GitHub Pages 使用 `main` 分支及 `/ (root)`。

本版 Service Worker 快取名稱：

```text
gpai-v515-20260726
```

若更新後仍顯示舊配色，可重新整理兩次；必要時到瀏覽器開發者工具的「Application／應用程式」清除舊 Service Worker 與網站資料。

## 執行自動化測試

```bash
pip install -r tests/requirements.txt
playwright install chromium
python tests/smoke_test.py
```

也可以測試已部署網站：

```bash
python tests/smoke_test.py https://example.github.io/project/
```

測試範圍包含：

- 完整 CSS 尚未載入時的首屏側邊欄配色
- 1440px 桌面、1024px 平板與 390px 手機版面
- 手機更多功能抽屜
- AI 採購老師、案例研習與法條比較
- 正式三節 225 題／780 分及跨節去重
- 快速測驗、交卷統計與備份資料驗證
